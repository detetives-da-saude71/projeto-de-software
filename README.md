# projeto-de-software
Este repositório contém o código-fonte e a arquitetura técnica do projeto Detetives da Saúde. O sistema foi projetado para ensinar sobre as doenças infecciosas com a diversão, oferecendo uma solução escalável, segura e de fácil usabilidade. O projeto abrange a implementação completa, incluindo front-end, back-end e integração com banco de dados.
